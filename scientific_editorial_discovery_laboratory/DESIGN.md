## Brand & Style

This design system embodies the rigor of modern academic publishing, the precision of advanced laboratory instrumentation, and the clarity of dynamic computational media. It bridges computational thinking and peer-reviewed clarity—evoking deep focus, intellectual quietude, and authoritative precision.

### Design Principles
- **Clarity Over Embellishment:** Whitespace is an active tool for cognitive headroom. Never fill space merely because it exists.
- **Instrumental Precision:** Controls, readouts, and data points are engineered with tactile, deliberate exactitude. 1px hairline divisions define boundaries rather than heavy drop shadows.
- **Typographic Rigor:** Distinguish clearly between discursive prose, UI operational controls, and symbolic or numerical values.
- **Quiet Modernity:** Avoid glossy glassmorphism, heavy gradients, or toy-like gamification. The visual language should feel at home alongside high-impact scientific publications and industrial-grade simulation platforms.

## Colors

The palette is anchored in warm stone and parchment-leaning paper tones, contrasting with a deep scientific cobalt and disciplined domain-specific indicators.

### Neutrals & Backgrounds
- **Canvas Base (`#FAFAF9`):** The primary root-level background for application frames and ambient workspaces.
- **Surface Level 1 (`#FFFFFF`):** Work panels, notebook blocks, code environments, and elevated canvas sheets.
- **Surface Level 2 (`#F4F4F2`):** Sidebar panels, toolbar ribbons, data tables, and inactive block regions.
- **Hairline Border Soft (`#E5E5E2`):** Primary dividing lines, card containers, and data cells.
- **Hairline Border Strong (`#D8D8D4`):** Active structural dividers, input boundaries, and panel splits.
- **Text Primary (`#1C1D1F`):** Deep charcoal ink for high-contrast reading.
- **Text Secondary (`#3F4145`):** Body notations, meta descriptions, and secondary metadata.
- **Text Muted (`#71737A`):** Captions, timestamps, inactive units, and formula annotations.

### Functional & Domain Accents
- **Cobalt Accent (`#1D4ED8`):** Primary system focus, execution triggers, active states, and cross-references.
- **Emerald Sage (`#059669`):** Biological systems, positive deltas, stable equilibria, and success verifications.
- **Amber Bronze (`#D97706`):** Thermodynamic states, warnings, variable overrides, and caution flags.
- **Amethyst (`#7C3AED`):** Abstract logical constructs, mathematical proofs, tensor shapes, and algebraic terms.
- **Cerulean (`#0284C7`):** Classical mechanics, fluid waves, vector dimensions, and network topologies.

Use domain accents strictly for semantic labeling, data visualization marks, and parameter groupings—never as arbitrary full-surface fills.

## Typography

The typographic hierarchy relies on a calibrated triad:

1. **Newsreader (Editorial & Display):** Grounded in academic publishing, monographs, and treatise headings. Used for section titles, narrative abstract blocks, and long-form scientific discourse.
2. **Geist (Application Interface & Dense Data):** Unembellished, ultra-legible modern sans used for operational menus, tooltips, dialogs, button controls, and table cells.
3. **JetBrains Mono (Symbols, Metrics & Formulae):** Tabular figures, units of measurement ($s^{-1}$, $mol$, $eV$), interactive code blocks, tensor shapes, and state badges.

### Typographic Rules
- In long-form scientific notes, maintain line lengths between 60 and 72 characters (`body-editorial`) for sustained reading comfort.
- Always enforce tabular numbers (`tnum`) in metric cards, tables, and instrumentation readout badges.
- Never use italic styles on the interface sans except for scientific citations or taxonomy nomenclature.

## Layout & Spacing

The system implements a structured multi-pane workbench model built on an 8-point structural rhythm with a 4-point sub-grid for dense instrumentation components.

### Layout Topology
- **Workbench Multi-Pane Split:** A 3-column paradigm on desktop:
  1. *Navigation / Cell Ledger:* Fixed width (240px–280px) for study navigation.
  2. *Narrative Notebook Canvas:* Fluid central document pane (max width 840px) centered with comfortable margins.
  3. *Instrumentation / Parameter Drawer:* Dockable inspector pane (320px–400px) containing dynamic dials, simulation feeds, and variable controllers.
- **Breakpoints:**
  - `Mobile (< 768px):` Single column stacked. Sidebars collapse into drawer sheets; simulation canvas drops below markdown prose.
  - `Tablet (768px - 1180px):` Two-column split with collapsible parameter drawer.
  - `Desktop (1181px+):` Full three-tier laboratory view.

### Spacing Guidelines
- Metric tiles and lab parameter grids use dense `space-xs` (8px) and `space-sm` (12px) spacing to preserve high data density.
- Narrative prose blocks maintain expansive vertical breathing room with `space-xl` (32px) margins between notebook modules.

## Elevation & Depth

This design system avoids traditional heavy blurred drop shadows in favor of architectural separation via **hairline division and tonal surfaces**.

### Layering Model
- **Base Canvas (Level 0):** `#FAFAF9`. The ambient desktop upon which notebooks rest.
- **Active Sheets & Notebook Cells (Level 1):** `#FFFFFF`, bounded by `1px solid #E5E5E2`.
- **Inspector Toolbars & Canvas Panes (Level 2):** `#F4F4F2`, bounded by `1px solid #D8D8D4`.

### Micro-Shadows (Tactile Affordances Only)
Shadows are reserved strictly for interactive float elements (popovers, active formula tooltips, floating command palettes) and dragged canvas nodes:
- **Popover / Flyout:** `0 1px 3px rgba(28, 29, 31, 0.04), 0 4px 12px rgba(28, 29, 31, 0.06)`.
- **Active Focused Cell:** Border transitions from `#E5E5E2` to `#1D4ED8` with an inset `0 0 0 1px #1D4ED8`. No colored diffuse glow.
- **Interactive Modals:** Flat backdrop scrim (`rgba(28, 29, 31, 0.25)`) with a clean `#FFFFFF` surface framed by `1px solid #D8D8D4`.

## Shapes

The geometric personality is quiet, functional, and disciplined. 

- **Level 1 (Soft):** 4px (`0.25rem`) default radius for operational components including buttons, formula inputs, slider handles, and tag badges.
- **Containers & Panels:** 6px (`0.375rem`) to 8px (`0.5rem`) for simulation canvas wrappers, data table containers, and notebook cell blocks.
- **Never Pill-Shaped:** Do not use full-pill rounded radii (`9999px`) on inputs or primary action buttons; pill shapes feel consumer-recreational and contradict the clinical laboratory environment. Small indicator dots (e.g., status LEDs) are circular.

## Components

### Buttons & Action Controls
- **Primary Button:** Background `#1D4ED8`, text `#FFFFFF`, border `1px solid transparent`, radius `4px`. On hover: `#1E40AF`.
- **Secondary / Outline Button:** Background `#FFFFFF`, text `#1C1D1F`, border `1px solid #D8D8D4`, radius `4px`. On hover: `#F4F4F2`.
- **Ghost Tool Button:** Background transparent, text `#3F4145`, radius `4px`. On hover: `#E5E5E2`, text `#1C1D1F`.
- **Typography:** `Geist` 13px, weight 500, height 32px (compact) or 36px (standard).

### Notebook Cells & Narrative Cards
- Container constructed of `#FFFFFF` surface with `1px solid #E5E5E2` border.
- Left-hand status gutter: a 3px hairline edge indicating execution state (Idle: transparent; Running: `#2563EB`; Success: `#059669`; Error: `#DC2626`).
- Header rail carries block identity (e.g., `In [14]`) formatted in `JetBrains Mono` 11px `#71737A`.

### Lab Parameter Sliders & Numeric Steppers
- **Track:** 2px solid horizontal line (`#E5E5E2`), active segment filled with domain color (e.g., Cerulean `#0284C7`).
- **Thumb:** 14px × 14px square or slightly rounded (2px) metal pip in `#FFFFFF` with `1px solid #3F4145` and subtle `0 1px 2px rgba(0,0,0,0.1)`.
- **Value Readout:** Embedded monospace input immediately adjacent, right-aligned, accepting direct typed input.

### Badges & Metadata Chips
- Height 22px, padding `0 6px`, font `JetBrains Mono` 11px uppercase.
- Neutral Chip: Background `#F4F4F2`, border `1px solid #E5E5E2`, text `#3F4145`.
- Biological / Living Tag: Background `rgba(5, 150, 105, 0.08)`, border `1px solid rgba(5, 150, 105, 0.25)`, text `#059669`.
- Mathematical Tag: Background `rgba(124, 58, 237, 0.08)`, border `1px solid rgba(124, 58, 237, 0.25)`, text `#7C3AED`.

### Input Fields & Formula Editors
- Height 34px, background `#FFFFFF`, border `1px solid #D8D8D4`, text `#1C1D1F`.
- Focused: Border `#1D4ED8`, outline none, box-shadow `0 0 0 1px #1D4ED8`.
- Formula Inline Inputs: Monospace font with light gray background `#F4F4F2` and dotted bottom border `#71737A`.

### Simulation Canvas & Viewport Frames
- Background `#FAFAF9` with faint 16px grid dots (`#E5E5E2`).
- Encapsulated by `1px solid #D8D8D4` with an integrated top breadcrumb strip showing frame rate, step time ($dt$), and zoom coordinate matrices.
